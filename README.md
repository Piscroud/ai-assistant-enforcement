JPJ Enforcement AI Assistant V1
Versi GitHub Pages bagi sistem rujukan JPJ Enforcement AI Assistant.
Logo JPJ
Logo yang digunakan ialah logo rasmi JPJ yang dirujuk daripada Portal Rasmi JPJ:
https://www.jpj.gov.my/maklumat-korporat-3/imej-jpj/logo-jpj/
GitHub Pages
Cipta repository GitHub baharu.
Muat naik semua fail dalam folder ini ke root repository.
Pergi ke Settings → Pages.
Pilih GitHub Actions sebagai sumber deployment jika diminta.
Workflow akan menerbitkan `index.html` sebagai laman GitHub Pages.
> Nota: Sistem ini masih menggunakan CDN untuk Tailwind CSS, Font Awesome dan Google Fonts, serta memuatkan logo rasmi JPJ daripada portal rasmi JPJ.
